# 枣子姐 Dot 桌宠持续迭代

目标：让角色表情更丰富，并在 Dot 的固定播放节奏、思考切换和鼠标注视中保持清醒、稳定、可读。任务正在推进，当前材料属于调试版本。

## 每轮执行方式

1. 将反馈记录为“触发动作 → 看到的问题 → 预期行为”，区分素材问题、预览误差和宿主限制。
2. 只修改受影响的源行，保留已经认可的身份、大小和其它动作。
3. 从最终编码图集生成正常速度预览，检查多圈循环、状态往返及深浅背景的小尺寸显示。
4. 重新运行相关质量检查；分别记录结构、视觉、模拟和真实 Dot 的证据。
5. 合格候选先展示，再同步到原云端条目和本地素材；保持回退版本，更新同一草稿 PR。
6. 未解决的问题进入下一轮，不把上传成功当作体验通过。

## Dot 适配边界

2026-10-02 曾检查的 Codex 26.928.3736.0 网页 Dot 组件自动选择待机行 0 或工作行 7；v2 注视可选择行 9–10。通用图集其它动作行存在，但该 Dot 状态选择器不会主动触发它们。以下为该版本的源码对照及预览模型依据，当前用户入口和新版 caller 另行核验。

- 待机六帧停留 1680、660、660、840、840、1920 ms，名义一轮 6.6 秒。首尾常态需要适合长时间停留。
- 工作六帧停留 120、120、120、120、120、220 ms，名义一轮 0.82 秒。表情应渐进，避免反复明暗闪变和闭眼节拍。
- 注视是静态覆盖，会暂停待机计时。退出后重新进入待机首帧；不能用素材宣称实现方向插值或注视时继续呼吸。
- 宿主使用延迟回调逐帧推进，不会按绝对时间跳帧追赶。各帧必须独立自然，延迟时不能卡在错误中间表情。
- 按对话语义自动选择情绪、精确眨眼时长和更多 Dot 状态触发需要宿主能力，当前没有已验证的素材接口支持。

上述数值属于所检查安装版本；网页实际实时节奏、后台节流和最终 Dot 交互分别核验。8 小时回归走虚拟时钟，不能称为连续运行 8 小时；模型不修改宿主 FPS。

## 每轮验收条件

- 人物身份、发饰、眼色和已接受缩放保持一致，透明边缘没有新增碎片或色块。
- 默认与工作不使用持续睡态；正常速度下表情可读，循环边界没有显著明暗或轮廓跳变。
- 检查 idle → work → idle、注视 → work、退出注视、反复切换和延迟回调，确保预览没有残留覆盖或重复计时器。
- 静态代码、离线质量报告、模拟检查和真实使用结果分开记录；未覆盖项保持待确认。
- 最终素材结构与质量检查通过，云端重新下载内容与本地解码一致；GitHub 提交只含公开改绘素材和工具。
