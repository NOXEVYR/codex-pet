## 分开验收普通悬停与离开头像

1. 指针先停在头像区域外，再自然移入；全程不按键。记录注视是否出现，以及鼠标在头像内移动时方向是否跟随。
2. 保持指针在头像内并停止移动，不点击；记录注视是维持、自动停止还是发生其它变化，以及实际观察时段。此项只验纯悬停。
3. 另开一次试验：自然移入后不点击，移出头像边界但留在同一页面。记录注视是否立即停止、继续显示或继续跟随页面内移动，以及它实际何时停止。此项只验退出机制，不把移出与点击混在一起。
4. 如需核对反馈中的点击现象，再用独立试验单独点击；记录点击前后的状态。若点击同时切换焦点、页面状态或对话状态，不能仅凭先后顺序认定是点击本身结束了注视。

## 10 秒 lease：仅作已检查实现的条件性对照

以下规则来自已检查的 Codex 26.928.3736.0、26.930.2377.0 特定网页 Dot 组件和 `dot-mode.mjs` 预览模型，不是当前用户入口的通用预期。只有入口和版本确认对应同一实现后，才用这些条件验收；无法对应时只记当前入口的实际表现及适用性未确认。当前检查的新版网页路径没有点击直接取消注视的监听，反馈中的点击退出原因仍待定位。

1. 在无点击的单独试验中自然移入，记录时段；模型在 outside→inside 时开始 10 秒 lease。保持在区域内，在约 7–9 秒时移动一次，再继续观察。该模型中区内移动不续期，到期清除注视；回调可能晚到，所以稍晚于 10 秒不直接判失败。
2. 另开试验，在 lease 未到期时移出头像并留在同一页面，再移动鼠标。该模型预期注视不会因移出立即清除，页面内移动仍可更新方向。
3. 到期时若仍在头像区域内，按该模型须先移出再进入；若到期时已在区域外，下一次进入即可建立新 lease。独立记录点击，不用模型推断当前入口的点击语义。
4. 对应实现确认后，注视清除时观察 idle F0 至下一帧；名义首帧停留为 1680 ms，迟到回调可使实际时长更长。采样不够密或有空档时，把驻留记为未判定。

## 自然状态切换

只观察用户已有且已授权任务自然发生的变化，不发送测试消息、不改任务内容，也不为验收自动创建新任务。没有自然边界就记“未发生，未测”。

- 对应已检查网页 Dot 实现的自然 idle → work → idle：预期从 idle row 0 切到 work row 7，工作结束后回到 row 0。观察帧顺序和循环；采样未捕获的短帧不能算作首帧已验证。
- 对应已检查网页 Dot 实现的注视期间进入 work：预期注视覆盖清除，切到 row 7；可在 work 期间自然移动一次鼠标，确认未重新出现注视覆盖。native 或其它入口先记录实际状态及覆盖行为，未确认对应路径时不按此预期判通过或失败。
- 每次只报告实际捕获的边界和往返次数。离线模拟、猜测会话状态或未观测空档都不能补成真实切换证据。

## 切换页签或窗口并返回

先按当前入口已确认的方式建立注视，再切到普通页签或其它窗口，之后返回原入口。验收记录必须能确认本次页面真实经历 `hidden → visible`；仅仅打开了另一个页签、但没有确认页面变成 `hidden`，不算覆盖 hidden。若页面仍 `visible` 但确实失去焦点，应单独记录为 blur；一次操作同时发生 hidden 和 blur 时，记录为联合场景。

分别记录隐藏前、返回后的注视覆盖和 idle 帧表现。取消注视、隐藏期间动画是否暂停及恢复帧位置，只有在确认入口对应已检查实现时才能按其模型作预期；未定位入口就如实记录，不判模型通过或失败。回调可以迟到，浏览器也可能节流。若隐藏期间无法观察，不推断其间的逐帧播放、精确取消时刻或屏幕呈现。需要确认 hidden/visible 状态时使用现有浏览器观测记录；无法确认就记“证据不足”，不要靠操作动作推断。

## 分开记录证据

- **源码审查**：说明代码路径和预期，不等于真实入口通过。
- **离线模拟**：说明模型在模拟条件下的行为，不等于浏览器或桌面运行。
- **短时 DOM 采样**：记录实际样式行列、起止时段及空档；DOM 帧格不代表屏幕 paint 或 FPS。
- **屏幕呈现 / paint FPS**：需要该类实际画面证据，不能从 DOM 读数推算。
- **真正长时运行**：记录连续真实起止时间；累计短片段或虚拟时钟不算长时验收。

被检查的实现按链式 timeout 逐帧推进，回调可能晚到。保留真实时间段和未观测空档，不要求每个周期严格等于名义时长；也不把隐藏前后相隔多帧直接称为追帧、跳帧或 FPS 变化。本指南只补充实际观察到的入口与场景，不能单独证明长时耐久或正式 Release。
