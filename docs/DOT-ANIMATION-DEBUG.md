# Dot 脸部动画调试

Dot 头像、Settings → Pets 的悬浮宠物和 Windows 的 NatsumePet 程序是不同入口。一个入口的文件或程序版本不能证明其它入口使用相同素材；应分别核对图集内容与 SHA-256。

## 已核对的宿主行为

以下节奏依据 2026-10-02 检查的 Codex 26.928.3736.0 安装版代码。宿主使用链式 `setTimeout`，每个延迟回调只推进一帧，再按回调时间安排下一帧；迟到时不会按绝对时间补帧。idle 六帧停留 `[1680, 660, 660, 840, 840, 1920]` ms，循环 6600 ms；work 行 7 六帧停留 `[120, 120, 120, 120, 120, 220]` ms，循环 820 ms。图集本身不能设置 FPS，改 GIF 演示速度也不会提高宿主更新频率。这些数值属于被检查的安装版本，不保证其它版本相同。

Dot 状态选择器只自动使用待机行 0 和工作行 7。通用图集虽然包含其它动作行，Dot 不会因此自动触发这些动作。v2 注视行 9–10 提供十六个静态方向；注视覆盖待机时会暂停待机计时，清除后从 idle 首帧重新等待完整 1680 ms。

注视 lease 在指针进入头像交互区域时建立 10 秒。移出区域不会立即取消；租期内全页主非触摸指针移动仍可改变方向，持续位于区域内的移动不会续期。到期时注视取消但保留内部“仍在区域内”状态，所以需先移出再进入才能重新开始。blur 和 document-hidden 会取消注视；document-hidden 不作为动画全局暂停，普通宿主计时器受浏览器节流，回调恢复后仍逐次推进一帧。

## 第二轮候选与模拟验收

[素材包](../pets/natsume-face-dot/README.md)保留第一轮改过的 idle 行 0；第二轮仅改 work 行 7，旧本地基准 SHA-256 为 `5fb8f25a57540be78224866ae6d711136259138039bc8098d681f6304baad5ec`。两轮累计改动行为 0 和 7。当前最终 WebP 为 1536×2288、8×11，2,739,714 bytes，SHA-256 为 `97ffec59aeab2288a88f27abc7f619de2571b5e4286c17a19896bf31b8bf040d`。

第二轮结构校验、编码质量检查和独立视觉复审均通过。最终 native 编码预览包括[工作五圈](../pets/natsume-face-dot/work-host-preview.gif)（4.1 秒）和[待机→工作→待机](../pets/natsume-face-dot/idle-work-host-preview.gif)（14.02 秒）；[待机预览](../pets/natsume-face-dot/idle-host-preview.gif)继续使用第一轮文件。工作表情与行布局预览通过不代表真实 Dot 已验收。

第一轮云端核验也曾确认同一条目的下载内容与当时本地素材一致、界面选择保持不变；本轮已用新文件和 fresh browser 选择状态重新核验。本地素材包更改仍不会自动更新云端条目。

源码回归共 27 项测试：14 项计时测试和 13 项状态/注视测试，包含通知原子性回归。独立审查另运行了 12 个 inline UI 模拟场景，并确认实际构建产物与页面逐字节一致。场景脚本的 33 项断言包含 8 小时虚拟时钟和交错注视/状态切换；这是模拟时长，不是连续真实运行 8 小时。模拟使用替身 DOM、画布和解码器，不能替代真实 Dot 端到端核验。

第二轮同步已由 root 核验：同一云端条目重新下载的 PNG 与候选、本地公开包、native 和 canonical 图集解码后逐像素一致；fresh browser 刷新后仍选中该条目，旧眨眼存档未选。该核验只证明素材内容和选择状态，真实 Dot 长时播放及 native UI 播放仍未验收。

后续改进聚焦待机浅笑/好奇变化，以及 067.5° 到 090° 注视姿态间的台阶。新改绘没有改变宿主 FPS，也没有修改 Windows NatsumePet 程序。

## 验收边界

- 在完整 6.6 秒 idle 与 820 ms work 循环中检查表情、呼吸、轮廓与循环边界，并查看 20、64、128、192 px 下的可读性。
- 使用最终编码图集检查 idle ↔ work、注视→work、blur/hidden、反复切换及延迟回调；结构、质量、视觉、模型模拟和真实 Dot 使用结果分别记录。
- 检查真实 alpha 与深浅背景边缘。透明像素中的 RGB 不等于可见脏边，不要仅按颜色删除发饰。
- 只有在实际 Dot 条目中完成交互验证后，才能记录真实体验通过。
