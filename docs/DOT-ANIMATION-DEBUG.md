# Dot 脸部动画调试

Dot 头像、Settings → Pets 的悬浮宠物和 Windows 的 NatsumePet 程序是不同的入口。程序版本 v0.5.9 不能证明三处动画素材一致；图集应通过稳定条目、图片内容和 SHA-256 比对。相同名称也不能作为唯一身份。

## 当前播放限制

2026-10-02 检查安装版 Codex 26.928.3736.0 的宠物渲染实现，待机六帧的停留时间为 1680、660、660、840、840、1920 ms，完整循环 6600 ms。旧的 1100 ms 演示把这一过程加快了六倍，会掩盖长时间闭眼的问题。工作行六帧的名义循环为 820 ms。

这些是该安装版本的实现事实，并不保证未来客户端保持相同数值。图集本身不包含可由编辑者设置的 FPS；上传更多图片、补中间姿态或改变 GIF 演示速度不能提高 Dot 的实际更新频率。网页的精确实时计时尚未独立测量。

Dot 常用待机行 0 和工作行 7。v2 的注视方向是十六张静态姿态；视线覆盖待机时，自动待机播放会暂停，清除后从首帧完整停留时间重新开始。其它动作能在预览工具中检查，但不能因此宣称 Dot 会按桌面宠物的触发方式调用它们。

## 动画验收

- 默认待机保持清醒；慢速待机不使用快速眨眼的过渡序列，也不以持续闭眼代替工作状态。
- 在完整正常循环中检查呼吸是否可见，头部是否胀缩、轮廓是否跳变；同时查看 20、64、128 和 192 px 下的可读性。
- 使用最终编码后的图集检查待机与工作、注视、跳跃的切换，保持人物身份和大小稳定。
- 检查真实 alpha 与合成后的边缘。透明像素中的 RGB 并不等于可见脏边，不能直接删除粉色发饰。
- 结构校验通过、预览通过和真实 Dot 体验通过分别记录。最终仍需在选中的 Dot 条目中确认实际效果。

[预览工具](../tools/dot-pet-preview/README.md) 只在本机读取用户选择的图集，不联网上传素材。待机正常节奏与旧演示节奏并排显示，便于识别验证方式的误差。当前工具经过计时和载入逻辑检查；本次自动浏览器策略禁止打开 file://，因此没有把真实浏览器本地 UI 验收列为通过。

## 本轮调试与待确认项

[2026-10-02 睁眼呼吸素材](../pets/natsume-face-dot/README.md) 仅替换待机行 0，保留行 1–10 和既有整体缩放。云端更新保留原条目 ID，重新下载的图片与本地最终 WebP 解码后逐像素一致；Dot 外观界面仍选中该条目。较旧的同名副本已标为存档。这确认了文件和选择状态，不能代替完整播放验收。

后续重点检查：

- 正常 6.6 秒待机起伏是否自然，思考开始和结束时能否正确切换工作动画。
- 退出鼠标注视后是否恢复待机，工作期间是否错误触发注视或出现方向偏移。
- 工作 F4 仍有偏担忧的表情，067.5° 到 090° 仍有转头台阶；两项属于保留素材的已知问题。
- 新待机默认轮廓约宽 4%，需在实际 idle/work/look 切换中确认是否产生可见跳变。

## 发布范围

本次调试不修改 Windows EXE 版本，也不覆盖历史发布包。尚未通过实际验收的素材不作为正式 Release。公开提交不包含游戏原始立绘、提取目录、私有对话、云端下载凭据或个人配置。
