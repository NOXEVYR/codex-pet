## 图集与验收

`spritesheet.webp` 为 1536×2288、8×11 的 v2 图集，73 个有效帧，15 个透明留白格，大小 2,739,714 bytes。SHA-256：

```text
97ffec59aeab2288a88f27abc7f619de2571b5e4286c17a19896bf31b8bf040d
```

图集结构校验、最终编码质量检查和独立视觉复审均已通过。源码回归覆盖 27 项测试，独立审查另通过 12 个 inline UI 模拟场景；场景脚本的 33 项断言覆盖 8 小时虚拟时钟和注视/状态切换。8 小时为模拟时长，不是连续真实运行；这些结果也不等同于真实 Dot 端到端验收。本轮同步已核验：保留原云端条目，重新下载 PNG 与候选、公开素材包及本地两处图集解码后逐像素一致；刷新后的浏览器确认当前条目仍选中，旧眨眼存档未选。该结果确认素材和选择状态，不证明 Dot 长时播放。本轮没有改变宿主 FPS。

第一轮也曾完成同一条目的云端同步核验；第二轮以上述重新下载内容和刷新后的选择状态重新核对。

待机帧停留为 `[1680, 660, 660, 840, 840, 1920]` ms，工作行按上述停留循环。图集仍不能改变宿主时序或自动新增状态触发。

后续迭代重点为待机浅笑/好奇变化，以及 067.5° 到 090° 注视姿态间的衔接；实际 Dot 表现仍需在同步核验后确认。结构、编码质量、视觉复审、模型模拟和真实 Dot 体验分别记录。

本地 Settings → Pets 使用同目录的 `pet.json` 和 `spritesheet.webp`；替换素材前保留原件并刷新宠物列表。该本地素材包不会自动同步云端，也未修改 Windows NatsumePet 程序。检查方法见[调试说明](../../docs/DOT-ANIMATION-DEBUG.md)，节奏与状态场景可用[本地预览工具](../../tools/dot-pet-preview/README.md)检查。
