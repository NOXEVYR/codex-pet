# Dot 宠物图集预览

双击打开 `index.html` 即可离线预览。页面只接受 PNG / WebP，最大 32 MiB，并校验尺寸为 1536 × 1872（v1）或 1536 × 2288（v2）。所选图片只解码到当前页面内存，不保存、不上传，也不修改原图。

32 MiB 是预览器的读入上限；Pets 正式导入上限为 20 MiB。这里的尺寸检查不检查角色语义、空帧或边缘质量，不能代替正式图集校验。

待机默认以 Dot 宿主节奏播放，并与旧预览的 1.10 秒节奏并排对照；名义宿主一轮是 6.60 秒。一个共享 `setTimeout` 调度宿主与旧预览中最早到期的帧，`requestAnimationFrame` 只绘制和更新读数。迟到回调每个时钟只推进一帧，下一帧从回调时刻开始完整计时；暂停、逐帧、视线、状态、循环和图集切换都会重排这唯一的定时器。工作中按已确认的 Dot 行为持续循环。额外动作标作桌面端扩展参考。角色框默认 64 px，帧格固定为 192 × 208，保持比例并采用像素化缩放。

默认 Dot 交互模式按所检查宿主的会话状态选行：空闲或未建立会话为待机，正在思考为工作，“任务暂歇”仅当前打开该会话时使用工作行。动效关闭显示当前状态首帧，恢复动效会重启。模拟失焦/隐藏会取消注视；隐藏不在模型中暂停动画，真实后台节流仍由浏览器处理，不能用该按钮宣称已经模拟真实后台性能。

视线格只支持 v2 待机。本工具的 Dot 模式依据曾检查的 Codex 26.928.3736.0 网页组件建立约 10 秒有效期：鼠标移出不会立即取消，期间全页主指针移动仍可改变方向，持续在范围内移动不会续期；到期后若仍在范围内，需要先移出再移入。失焦、隐藏、明确取消或进入工作会结束该模型的注视。原有“移出即取消”只保留在手动预览模式。这两种预览规则都不能直接代表其它版本或 Settings → Pets 悬浮入口。

第四轮收到人工反馈：普通悬停会持续跟随鼠标，直到点击才停止，用户已确认入口是网页“你的 dot”头像。本机运行版本为 Codex 26.930.2377.0；只读检查确认其安装包内的网页组件仍有十秒期限，native 悬浮路径则接收上游点位。桌面应用版本不等于 chatgpt.com 网站构建，尚未建立当前网站与被检查源码的版本关系。静止时长、重入轨迹和点击是否打开外观面板仍待实测，不能把模型的十秒到期当作当前网站的通过条件。预览界面明确标为“网页 Dot 交互模型”，播放逻辑未改。具体步骤见[实际交互验收指南](../../docs/DOT-INTERACTION-CHECK.md)。

结束视线覆盖会重启待机首帧并完整停留 1680 ms；如果此前用预览器手动暂停，会保留暂停状态。暂停/逐帧是本工具的检查操作，不是 Dot 设置。切换播放状态从所选状态首帧开始；载入新图集重置首帧并保留手动暂停。Dot 模式持续循环，选择扩展动作会转为手动模式；手动模式支持更改循环、单次完成后重播。

连续选择图集时以最后一次选择为准，过期的解码结果会丢弃。v1 图集会关闭 v2 视线开关。

`index.html` 是可双击使用的独立页。修改 `timing.mjs`、`dot-mode.mjs` 或 `viewer.mjs` 后运行 `node build-preview.mjs`，重新内联代码。计时与状态测试运行：

```sh
node --test meaningfultiming.test.mjs dot-mode.test.mjs
node run-dot-scenarios.mjs > scenario-report.json
```

页面没有第三方依赖，也不访问网络。图集状态随页面关闭而清除。

既有预览代码曾通过 27 项回归测试、12 个 inline UI 模拟场景和 33 项场景断言（含 8 小时虚拟时钟与交错注视/切换）；这些结果继承自未改动的预览代码，本轮只更新素材而未重跑测试。8 小时是模拟时长，不代表真实 Dot 连续运行 8 小时；模拟使用替身 DOM、画布和图片解码器，不能替代真实交互或耐久检查。

## 实际网页 DOM 时序样本

第三轮 DOM 样本包括会话 work（120 次、约 7.167 秒，7 周期平均 844.3–877.3 ms）、外观编辑器 idle（240 次、约 10.408 秒，仅一完整周期 6547–6731 ms）和同步后的真实会话 idle（840 次、两段共观察到 36 次顺序转帧和 4 个完整周期）。真实 idle 的周期区间包含 6600 ms，但严格固定 phase 区间不成立；名义最小驻留加回调延长相容。详细范围与空档处理见[调试说明](../../docs/DOT-ANIMATION-DEBUG.md)。DOM 读数不是屏幕 paint/FPS、精确转帧时刻或长时运行证明，编辑器 idle 也不是会话 idle；网页样本与本工具的虚拟时钟回归是不同证据。
