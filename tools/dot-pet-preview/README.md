# Dot 宠物图集预览

双击打开 `index.html` 即可离线预览。页面只接受 PNG / WebP，最大 32 MiB，并校验尺寸为 1536 × 1872（v1）或 1536 × 2288（v2）。所选图片只解码到当前页面内存，不保存、不上传，也不修改原图。

32 MiB 是预览器的读入上限；Pets 正式导入上限为 20 MiB。这里的尺寸检查不检查角色语义、空帧或边缘质量，不能代替正式图集校验。

待机默认以 Dot 宿主节奏播放，并与旧预览的 1.10 秒节奏并排对照；名义宿主一轮是 6.60 秒。一个共享 `setTimeout` 调度宿主与旧预览中最早到期的帧，`requestAnimationFrame` 只绘制和更新读数。迟到回调每个时钟只推进一帧，下一帧从回调时刻开始完整计时；暂停、逐帧、视线、状态、循环和图集切换都会重排这唯一的定时器。工作中按已确认的 Dot 行为持续循环。额外动作标作桌面端扩展参考。角色框默认 64 px，帧格固定为 192 × 208，保持比例并采用像素化缩放。

视线格只支持 v2 待机。结束视线覆盖会重启待机首帧并完整停留 1680 ms；如果此前用预览器手动暂停，会保留暂停状态，但帧仍重置到首帧。切换播放状态会从所选状态首帧开始。载入新图集会重置当前状态到首帧，并保留手动暂停。更改循环选项也重置到首帧，并保留手动暂停。单次播放结束时显示完成，点击“重播”会从首帧开始。

连续选择图集时以最后一次选择为准，过期的解码结果会丢弃。v1 图集会关闭 v2 视线开关。

`index.html` 是可双击使用的独立页。修改 `timing.mjs` 或 `viewer.mjs` 后运行 `node build-preview.mjs`，重新内联代码。纯计时测试运行：

```sh
node --test meaningfultiming.test.mjs
```

页面没有第三方依赖，也不访问网络。图集状态随页面关闭而清除。
